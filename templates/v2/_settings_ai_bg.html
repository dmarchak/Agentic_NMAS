Background features

{{ info('settings-ai', 'background-features', 'How background features work') }}

A background feature calls the model with no person pressing, only when Mercury's own checks have found something. Each is off on every network until an admin turns it on here, after its estimate, with its own day and month caps inside the installation's. An approval lasts {{ ai.approval_days }} days. Reaching a cap stops that feature and raises a Needs attention row; Mercury never raises a cap. A network never inherits another's switch.
