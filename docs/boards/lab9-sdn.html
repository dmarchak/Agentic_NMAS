Decisions: practice decides D1 to D6 (cited in docs/LAB9_SDN_GAP.md, section 5); D7 and D8 are the operator's.

D1 · Where OpenFlow onboarding lives

  1. Recommended: SDN › Switches, a new tab, with each switch's own device page linking to its row. The join (NetBox, the controller, the switch) is a fabric's question, asked across switches.
  2. On each device page only: no fleet view of which switches failed to connect.

D2 · The DNS filter: Mercury's or a service it steers to

  1. Recommended: a service Mercury steers to and reads (like Kea): Mercury owns the flows, settings and health; the filter itself is lab tooling. DNS-layer security products are resolvers a network steers to.
  2. Build the resolver into Mercury: a DNS server inside a control plane, and a second thing to keep secure.

D3 · Protected flows: where they are defined

  1. Recommended: NetBox Services tagged protected and the management prefix, added from SDN › Protected as a confirmed NetBox write; one check in the flow write path every writer shares.
  2. A Mercury setting: a second source of truth for facts NetBox models.

D4 · The trace's home

  1. Recommended: Topology › Path…, with the flow tables as a "Through" choice; SDN › Flows links to it. One home per action.
  2. A new SDN › Trace tab: two path tools that answer differently.

D5 · Link failure: who repairs

  1. Recommended: local repair where the switch has fast-failover groups (installed from policy), verified by the loop; elsewhere the loop proposes reroute flows (HITL) or applies them (AUTO on a lab-marked network). Local repair first, then re-optimisation.
  2. Only the controller application reroutes: Mercury could not show or verify it.

D6 · A model tier per network

  1. Recommended: economy or standard per network; a feature offered on a model only once its recorded cases ran on it, otherwise drawn disabled with that reason.
  2. A model per feature per network: many settings, each needing its own measurement.

D7 · The operator's: identity on the laptop

  1. A single-user local provider for this install kind, time-boxed (1.5 days; an exception to the no-localhost rule and to the Keycloak decision).
