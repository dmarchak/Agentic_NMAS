The fix choice on an incident's card (signed off under the Phase 7 mode)

One list, "Fixes for this problem", in place of a row of buttons. Each row: the fix's name (its page), its mode, how often it ran and its last result, one small Run bound to the hash its preview drew; its second line, closed, says what it does here and opens to what it sends, checks and verifies. Hand over… stays separate, under the list.

A. Two saved fixes match: one list, one Recommended (with why), every Run alike

The status line counts them and points at the list; the story's Next line does too, never "no configuration fix can cure this". The Manual row matches any port: Make this fix automatic? is not offered (its mode's hover says why).
