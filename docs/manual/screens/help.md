# Help

This manual, and what this installation is running.

## How the manual is organised {#organisation}

- **Getting started**: the model the tool is built on, and the third-party components it is
  built with, each with its version and licence.
- **How it works**: each operation, step by step: what happens, in what order, what is read,
  sent and recorded, and why.
- **Concepts**: the ideas several operations share: drift, how a baseline is earned,
  merge-only and Mode B, and a credential's life.
- **Screens**: one page per sidebar item, and the device page's tabs.

Below them, **About** opens this installation's own page (below).

Every screen has an info link that opens its page here, in a panel beside what you are doing.

## About this installation {#about}

Help > About opens with {{product}} itself:
- its full name and what it does;
- the commit it is running (a release number comes with the public release);
- its licence, still the operator's choice (Apache-2.0 recommended);
- a link to [the third-party components](third-party).

Below that are the facts about this installation: the commit the app is running, its CI
verdict, whether it is what is pushed, the last update, the checkout, who you are (as the
tool established it), and the Update button (see [Update the app](update)).
