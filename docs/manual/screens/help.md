# Help

This manual, and what this installation is running.

## How the manual is organised {#organisation}

- **Getting started**: the model the tool is built on.
- **How it works**: each operation, step by step: what happens, in what order, what is read,
  sent and recorded, and why.
- **Screens**: one page per sidebar item, and the device page's tabs.

Every screen has an info link that opens its page here, in a panel beside what you are doing.

## About this installation {#about}

Help > About shows the commit the app is running, its CI verdict, whether it is what is
pushed, and the Update button (see [Update the app](update)).
