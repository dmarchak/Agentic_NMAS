# Settings

The tool's configuration: integrations, the monitoring connectors, checks, and diagnostics.
The sidebar item opens today's Settings until the redesign splits it (plan 7.7).

## What it is for {#what-it-is-for}

- **Integrations**: NetBox, Prometheus, Grafana, Loki, Oxidized, Kea and the rest, each with a
  Test that checks it live.
- **The security posture**: who may reveal a secret, approve or confirm, read-only, each with
  where its value comes from.
- **Secrets are write-only**: a set secret shows as "set", never its value.
