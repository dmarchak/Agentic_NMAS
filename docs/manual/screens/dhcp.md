# DHCP

The DHCP server's subnets, pools, leases and reservations, read from Kea. The sidebar item
opens today's view until the redesign builds it.

## What it is for {#what-it-is-for}

Seeing which address a device holds and why: a lease is a fact about the device; a
reservation is a statement of intent. Onboarding by DHCP or ZTP writes a reservation; see
[Onboard a device](onboard).
