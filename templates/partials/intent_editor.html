{# Committed intent editor — Stage 3.1. TEXT, not fields, and the reason is not taste. A structured editor round-trips the document through the model, so anything the field set does not cover — the `unmodeled:` block above all — vanishes from the file without appearing in any diff. That is the precise failure `unmodeled` was built to prevent. Text also means the bytes reviewed in the diff are the bytes committed, with no translation layer in between. Honest is not the same as usable, so two things make it usable: * validation refuses with a LINE AND COLUMN, as the template editor does for Jinja; * the RENDER DIFF is shown before committing, so somebody who does not remember the schema sees the consequence rather than the document. #}
